The Standard

What makes an object worthy?

We believe value is felt before it is priced. Material, finish and craftsmanship should make an object feel exceptional.

01

Material

The material must feel right before anything else matters. Weight, texture, drape and durability are part of the design.

02

Construction

Details should remain convincing under close inspection — seams, edges, alignment, finishing and touch.

03

Purpose

Beauty is not enough. An Obscura object should function naturally and reward repeated use.

04

Permanence

We favour objects intended to live beyond a season rather than products created for constant replacement.
